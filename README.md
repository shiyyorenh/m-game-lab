# m-game-lab

## 项目简介

`m-game-lab` 是一个用于归档与发布多个独立 HTML 页面的仓库。这些页面通常包含小型实验、交互原型或静态游戏，以独立的 HTML 文件形式存在，不依赖于特定域名或后端服务。本仓库旨在提供一个整洁、可浏览的存档空间，方便回顾与分享。

## 目录说明

仓库根目录下按页面功能或主题进行分组，每个子目录对应一个独立的 HTML 页面及其相关资源（如 CSS、JavaScript、图片等）。

```
m-game-lab/
├── page-1/          # 页面 1 的目录
│   ├── index.html
│   └── assets/
├── page-2/          # 页面 2 的目录
│   ├── index.html
│   └── assets/
└── README.md        # 本文件
```

每个页面目录均包含一个 `index.html` 作为入口文件，可直接在浏览器中打开使用。

## 页面归档说明

- 所有页面均为纯前端实现，无需服务器支持，双击 `index.html` 即可运行。
- 页面内容可能包含交互式演示、小游戏、工具或学习笔记，风格与复杂度各异。
- 部分页面可能依赖外部库（通过 CDN 加载），请确保网络通畅。
- 页面可能未经过大规模测试，在不同浏览器或设备上表现可能略有差异。

## 维护说明

- 本仓库由个人维护，不定期添加新页面或更新已有内容。
- 欢迎通过 Issue 提交建议或报告问题，但请注意本仓库不提供技术支持。
- 如有意贡献，可提交 Pull Request，但请保持页面独立性与简洁性。
- 所有页面遵循 MIT 协议，具体请参见每个页面目录内的 LICENSE 文件（如有）。
